# 📘 Lógica de Programação com Visualg

Repositório com exercícios práticos de **Lógica de Programação** desenvolvidos em **Visualg**, com foco em algoritmos do dia a dia e boa organização de código.

---

## 🎯 Objetivo

Este repositório tem como objetivo registrar e organizar meus exercícios de lógica de programação, servindo como material de estudo e portfólio de aprendizado.

---

## 🛠️ Tecnologias Utilizadas

- **Visualg** (Portugol)
- Lógica de Programação
- Estruturas condicionais e de repetição

---

## 📂 Exercícios Disponíveis

| Arquivo | Descrição |
|--------|---------|
| `ConversorDeMoedasComSoma.alg` | Converte valores de Real para Dólar e acumula o total das conversões |
| `Calculo_Media_Aluno.alg` | Calcula a média de duas notas e informa se o aluno foi aprovado, está em recuperação ou reprovado |
| `calculadora_imc.alg` | Calcula o IMC e classifica o peso |
| `imc_meta_peso.alg` | Calcula o IMC e mostra quanto a pessoa precisa ganhar ou perder |
| `emprestimo.alg` | Sistema de aprovação de empréstimo com base na renda |
| `calculadora_concreto.alg` | Calcula a quantidade de materiais para concretagem |
| `calc.desconto.alg` | Calcula desconto com base no valor da compra |
| `SomadorComMaiorEMenor.alg` | Soma valores e identifica o maior e o menor número digitado |

---

## 🚀 Como executar

1. Baixe e instale o **Visualg**
2. Abra o arquivo `.alg` desejado
3. Clique em **Interpretar** (ou pressione `F9`)
4. Siga as instruções na tela
